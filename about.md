# Percent Frame Window

Frame window counter for **percent-macro** position macros, measured in physics ticks (240 TPS).

Pause menu → **Frame Window** → pick a macro from the percent-macro `macros` folder → **Analyze**.
For every click and release the mod replays the level with that input moved earlier/later and reports how many ticks it can move and still survive, e.g. `[-2,+2] 5F`.

Results are shown at the end and saved as `.txt` and `.csv`. Pause during analysis to cancel.
